# 会员能力上线准备

## 产品原则

免费版保留基础词表、每日学习、错词复习、学习记录和本机数据导出。会员出售经过验证的长期价值：完整高考词汇内容、跨设备同步、智能复习节奏、家长独立查看和教师任务管理。

不以隐藏学习记录、夸大提分效果或对未成年人进行高频催促作为付费手段。

## 上线前必须具备

1. 以 2–4 周真实试用证明 D+7 保持率、任务完成率和单位有效学习分钟的记忆量改善。
2. 登录、学生同意的家长绑定、解绑、数据导出和永久删除。
3. 试用、价格、自动续费、取消、退款与到期后数据访问的清晰说明。
4. 家长只能查看被授权的学习摘要；教师只能查看被学生或监护人授权的班级数据。
5. 支付、订阅和身份系统通过独立服务端实现，不将支付凭据或身份信息存入 GitHub Pages 本地存储。

## 会员版本优先顺序

1. 账号与安全云同步；
2. 家长周报和低频提醒；
3. 老师任务、班级汇总和证据导出；
4. 完整经校对词库与智能调度；
5. 订阅支付。
