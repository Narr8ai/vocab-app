## 📋 部署步骤（手机端）

### 第 1 步：创建 GitHub 仓库

1. 打开浏览器，访问 https://github.com/new
2. 登录你的 GitHub 账号（没有的话先注册）
3. Repository name 填写：`vocab-app`
4. 选择 **Public**（公开）
5. 勾选 **Add a README file**
6. 点击 **Create repository**

### 第 2 步：上传文件

1. 在新建的仓库页面，点击 **Add file** → **Upload files**
2. 点击 **choose your files**
3. 选择并上传这两个文件：
   - `index.html`
   - `flowchart.html`
4. 在 Commit changes 区域，点击 **Commit changes**

### 第 3 步：启用 GitHub Pages

1. 点击仓库顶部的 **Settings**（设置）
2. 左侧菜单找到 **Pages**
3. 在 **Source** 区域：
   - Branch 选择：`main`
   - 文件夹选择：`/ (root)`
4. 点击 **Save**
5. 等待 1-2 分钟

### 第 4 步：访问你的网站

刷新 Pages 页面，你会看到：

```
✅ Your site is live at https://你的用户名.github.io/vocab-app/
```

点击链接即可访问！
